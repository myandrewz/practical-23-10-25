# 🔁 ZeroEvenOdd Printer

This Python script prints a sequence where each number from `1` to `n` is preceded by a zero. It demonstrates basic class structure, control flow, and conditional logic.

## 📦 Overview

The `ZeroEvenOdd` class takes an integer `n` and prints a sequence of `0` followed by numbers from `1` to `n`, alternating between even and odd logic.

## 🧠 How It Works

- For each number `i` from `1` to `n`:
  - Print `0`
  - If `i` is even, print `i` using the `even()` method
  - If `i` is odd, print `i` using the `odd()` method
